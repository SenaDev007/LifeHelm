Politique de confidentialité

Application LifeHelm — édité par YEHI OR Tech

Dernière mise à jour : 25 octobre 2026

Cette politique décrit quelles données personnelles l'application LifeHelm traite, pourquoi, où elles sont stockées et quels sont vos droits. Elle est rédigée dans un langage simple et s'applique à l'application mobile LifeHelm pour Android.

1. Qui sommes-nous

LifeHelm est une application d'organisation personnelle et familiale (finances, calendrier, listes, notes, tâches, prêts) développée et éditée par YEHI OR Tech. Pour toute question relative à vos données : contact@yehiortech.com.

2. Données que nous traitons

a) Données de compte (uniquement si vous créez un compte)

  • Nom d'affichage que vous choisissez ;
  • Numéro de téléphone ou adresse e-mail — servant d'identifiant de connexion ;
  • Mot de passe (jamais stocké en clair : seule son empreinte cryptographique est conservée sur nos serveurs) ;
  • Si vous les activez : code de double authentification (TOTP) et réponses aux questions de sécurité de récupération.

b) Données que vous saisissez dans l'application

  • Module finances : comptes (nom, type, solde initial), opérations, prêts et échéances, budgets ;
  • Modules organisation : événements de calendrier, listes, notes, tâches, bilan de vie, profil de carrière ;
  • Photo de profil : uniquement si vous en choisissez une ;
  • Espaces partagés : le nom et le rôle (propriétaire, administrateur, membre…) des personnes que vous invitez.

c) Données techniques

  • Un jeton d'appareil (token) nécessaire à l'envoi des notifications (rappels, briefings), géré par Google Firebase Cloud Messaging ;
  • Les journaux techniques de nos serveurs (adresses IP, horodatages) à des fins de sécurité et de lutte contre les abus, conservés quelques mois.

3. Accès à vos contacts

Si vous utilisez le carnet d'adresses intégré (messagerie), LifeHelm demande l'autorisation de lire vos contacts. Cet accès sert uniquement à afficher et sélectionner vos correspondants au sein de l'application. Vos contacts ne sont ni copiés, ni transférés, ni stockés sur nos serveurs. Si vous refusez cette autorisation, le reste de l'application reste pleinement fonctionnel.

4. Où sont stockées vos données

LifeHelm fonctionne selon le principe « local d'abord » :

  • Sur votre appareil : toutes vos données sont enregistrées dans une base locale (SQLite) qui reste accessible hors connexion ;
  • Sur nos serveurs de synchronisation (uniquement si vous créez un compte) : une copie protégée en transit (HTTPS) de vos données permet de les retrouver sur un nouvel appareil et de partager vos espaces familiaux ou professionnels ;
  • Chez Google (Firebase) : le jeton de notification de votre appareil, afin de vous envoyer les rappels que vous avez programmés. Aucun autre usage n'en est fait.

5. Ce que nous ne faisons pas

  • Nous ne vendons ni ne louons vos données à des tiers ;
  • Nous n'affichons aucune publicité et n'intégrons aucun réseau de publicité ni traceur tiers ;
  • Nous n'analysons pas votre comportement à des fins commerciales ;
  • Nous ne lisons pas vos messages ni le contenu de vos contacts.

6. Durée de conservation

Vos données sont conservées aussi longtemps que votre compte existe. Sans compte, vos données restent uniquement sur votre appareil jusqu'à la désinstallation de l'application. Lorsque vous supprimez votre compte depuis l'application, vos données synchronisées sont supprimées de nos serveurs, à l'exception des journaux techniques conservés un temps limité (sécurité, obligations légales).

7. Vos droits

Conformément au Règlement général sur la protection des données (RGPD) et à la loi béninoise n° 2017-20 sur la protection des données à caractère personnel, vous disposez des droits suivants :

  • Accès : connaître les données que nous détenons sur vous ;
  • Rectification : corriger vos informations à tout moment depuis l'application ;
  • Suppression : effacer votre compte et vos données ;
  • Portabilité : obtenir une copie de vos données ;
  • Retrait du consentement : refuser les notifications ou l'accès aux contacts à tout moment dans les réglages d'Android.

Pour exercer ces droits, écrivez à contact@yehiortech.com. Nous répondons dans un délai maximum de 30 jours.

8. Sécurité

Les échanges entre l'application et nos serveurs sont protégés par le protocole HTTPS. Les mots de passe sont hachés, jamais stockés en clair. Les données locales de votre appareil bénéficient du chiffrement du système Android. Aucune mesure de sécurité n'étant absolue, nous vous invitons à protéger votre appareil par un code de déverrouillage.

9. Enfants

LifeHelm n'est pas destinée aux enfants de moins de 13 ans et nous ne collectons pas sciemment de données les concernant. Si vous estimez qu'un enfant nous a transmis des données personnelles, contactez-nous afin de les supprimer.

10. Modifications de cette politique

Nous pouvons faire évoluer cette politique pour refléter les changements de l'application. Toute modification substantielle vous sera notifiée dans l'application avant de prendre effet. La date de dernière mise à jour figure en tête de ce document.
